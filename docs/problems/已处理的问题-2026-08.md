# 已处理的问题 - 2026-08

## 1. Mixin 配置包路径错误

**日期**：2026-08-22

**问题描述**：`createprism.mixins.json` 中 `package` 字段写为 `com.adonis.createprism.mixin`，但实际 Java 代码包路径是 `com.adonis.prism.mixin`。若启用 mixin 会导致类找不到。

**修复**：将 `package` 字段改为 `com.adonis.prism.mixin`。

**文件**：`src/main/resources/crystal_clear.mixins.json`

---

## 2. AccessTransformer 包含不相关条目

**日期**：2026-08-22

**问题描述**：`accesstransformer.cfg` 暴露了 `FishingHook$OpenWaterType` 及相关方法，与当前 Mod 的玻璃机壳功能完全无关，疑似从其他项目残留或计划中功能的预备代码。

**修复**：清空 AT 条目，保留文件并添加注释说明。后续如有需要可再添加。

**文件**：`src/main/resources/META-INF/accesstransformer.cfg`

---

## 3. GitHub Actions JDK 版本不匹配

**日期**：2026-08-22

**问题描述**：`.github/workflows/build.yml` 和 `gradle-publish.yml` 使用 JDK 17，但 `build.gradle` 要求 `JavaLanguageVersion.of(21)`，CI 构建会失败。

**修复**：两个 workflow 中的 JDK 版本从 17 改为 21。

**文件**：`.github/workflows/build.yml`、`.github/workflows/gradle-publish.yml`

---

## 4. 创造模式标签页中包裹轴/齿轮被注释

**日期**：2026-08-22

**问题描述**：`CPCreativeTab.java` 中所有玻璃/通透玻璃/照明包裹轴和齿轮的展示代码被注释掉，玩家在创造模式无法直接获取这些方块。

**修复**：取消注释，启用所有包裹轴和齿轮的创造栏展示。

**文件**：`src/main/java/.../registry/CPCreativeTab.java`

---

## 5. Mixin 配置 package 字段未随包名重构更新

**日期**：2026-08-23

**问题描述**：包名从 `com.adonis.prism` 重构为 `io.liujiewentt.crystal_clear` 后，`crystal_clear.mixins.json` 的 `package` 字段仍为旧值 `com.adonis.prism.mixin`，未同步更新。Mixin 启用后会因找不到类而失败。

**修复**：将 `package` 字段改为 `io.liujiewentt.crystal_clear.mixin`。

**文件**：`src/main/resources/crystal_clear.mixins.json`

---

## 6. neoforge.mods.toml 模板 [[mixins]] 块含多余 file= 行

**日期**：2026-08-23

**问题描述**：`neoforge.mods.toml` 模板的 `[[mixins]]` 块下有一行 `file="META-INF/accesstransformer.cfg"`，这不是 mixins 配置的有效字段（AT 已在 `build.gradle` 中通过 `accessTransformers` 正确注册），可能导致模组加载时解析异常。

**修复**：删除 `[[mixins]]` 块下的 `file="META-INF/accesstransformer.cfg"` 行，仅保留 `config="${mod_id}.mixins.json"`。

**文件**：`src/main/templates/META-INF/neoforge.mods.toml`

---

## 7. Copper 照明包覆系列未注册

**日期**：2026-08-23

**问题描述**：`CasingTypes.ILLUMINATION_ENCASED` 枚举缺少 `copper` 条目，导致铜材质没有照明包覆轴/齿轮的注册。资源文件（blockstate、model、casing 贴图）均已齐备，仅缺代码注册和语言文件条目。此问题是原作者 Adonis 遗留的未完成功能，在 LoneStarFateZero 修复版中也存在。

**修复**：
1. `CasingTypes.java` 的 `ILLUMINATION_ENCASED` 枚举中加入 `createHolder("copper", AllBlocks.COPPER_CASING)`
2. `en_us.json` 和 `zh_cn.json` 各补充 3 条翻译：`copper_illumination_encased_shaft`、`copper_illumination_encased_cogwheel`、`copper_illumination_encased_large_cogwheel`

**文件**：`src/main/java/.../util/CasingTypes.java`、`src/main/resources/assets/crystal_clear/lang/en_us.json`、`src/main/resources/assets/crystal_clear/lang/zh_cn.json`

## 8. 包覆轴/齿轮未注册应力值为 0

**日期**：2026-08-23

**问题描述**：玻璃/照明包覆轴和齿轮未通过 `BlockStressValues.IMPACTS.register(block, () -> 0)` 注册应力值。参考项目 c0nnor263 版对 glass encased shaft/cogwheel 均做了此注册。缺少注册可能导致 tooltip 中显示的应力值与实际行为不一致。

**修复**：在 `GlassBlockBuilders.java` 的 4 个 builder 方法（`glassEncasedShaft`、`illuminationEncasedShaft`、`glassEncasedCogwheel`、`illuminationEncasedCogwheel`）中各添加 `.onRegister(block -> BlockStressValues.IMPACTS.register(block, () -> 0))`，并添加对应 import。

**文件**：`src/main/java/.../registry/builders/GlassBlockBuilders.java`

---
