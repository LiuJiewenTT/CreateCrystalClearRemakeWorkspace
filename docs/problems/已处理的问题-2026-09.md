## 18. GlassEncasedPipeBuilder 缺失 PipeAttachmentModel 注册

**日期**：2026-09-05

**问题描述**：`GlassBlockBuilders.java` 中的 `glassEncasedPipe()` 和 `illuminationEncasedPipe()` 两个 builder 方法未注册 `.onRegister(CreateRegistrate.blockModel(() -> PipeAttachmentModel::withAO))`。原版 Create 的 `ENCASED_FLUID_PIPE` 注册链中有此注册，用于启用管道接口动态渲染（`getRenderTypes` 和 `useAmbientOcclusion`）。

**根因分析**：阶段六开发时参照了轴/齿轮包覆的 builder 模式，但水管包覆需要额外的 `PipeAttachmentModel` 注册才能正确处理管道渲染逻辑，此步骤在可行性探索报告中已记录（2.5 节），但在实现时遗漏。

**修复**：
1. 在 `GlassBlockBuilders.java` 中添加 `PipeAttachmentModel` import 和 `blockModel` 静态导入
2. 在 `glassEncasedPipe()` builder 链中添加 `.onRegister(blockModel(() -> PipeAttachmentModel::withAO))`
3. 在 `illuminationEncasedPipe()` builder 链中添加 `.onRegister(blockModel(() -> PipeAttachmentModel::withAO))`

**说明**：此注册对渲染内部铜管无效（原因见 #19），但对 `getRenderTypes` 和 `useAmbientOcclusion` 仍有作用，应保留。

**编译验证**：BUILD SUCCESSFUL

**文件**：`src/main/java/io/liujiewentt/crystal_clear/registry/builders/GlassBlockBuilders.java`

## 21. 水管内部铜管不渲染

**日期**：2026-09-05

**问题描述**：玻璃机壳包覆铜水管后，内部铜管不可见。用户反馈希望看到内部铜管（透视效果）。

**根因分析**（深入排查结论）：

原版 Create 的铜机壳包覆水管（`ENCASED_FLUID_PIPE`）本身也不渲染内部铜管。原因链如下：

1. `FluidPipeBlock.isPipe(state)` 检查 `state.getBlock() instanceof FluidPipeBlock`
2. `EncasedPipeBlock extends Block`（不是 `FluidPipeBlock`），因此 `isPipe()` 对包覆水管返回 false
3. `shouldDrawCasing()` 依赖 `isPipe()`，返回 false → `isEncased` 为 false → `FLUID_PIPE_CASING`（3D 外壳）不渲染
4. `FluidPipeBlockEntity` 内部类 `StandardPipeFluidTransportBehaviour.getRenderedRimAttachment()`（第 65 行）明确判断：
   ```java
   if (state.getBlock() instanceof EncasedPipeBlock && attachment != AttachmentTypes.DRAIN)
       return AttachmentTypes.NONE;
   ```
   即对所有 `EncasedPipeBlock` 子类，管道接口附件类型返回 `NONE`，partials 为空数组，不渲染任何管道接口

**结论**：这不是 bug，而是原版设计。包覆后可见的只有 blockstate JSON 静态模型（`block_flat`/`block_open` 薄片外壳）。

**用户决定**：用户希望未来实现玻璃机壳独有的透视内部铜管效果，但当前先搁置以避免工作流杂乱。已记录至潜在问题与未来参考事项。

**可能的实现方向**（待后续启动时评估）：
- 自定义 `FluidTransportBehaviour` 子类不返回 `NONE`
- 自定义 `PipeAttachmentModel` 子类强制渲染 `FLUID_PIPE_CASING`
- 在模型中直接加入铜管 3D 元素

**文件**：无修改（搁置）
