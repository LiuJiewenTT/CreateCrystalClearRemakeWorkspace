# 文档编写指导

- 要编写计划文件，过往的计划可以转存到别的文件存档，但不要彻底删除，这是工作记录（简要）。
- 过程中处理了的问题，记录到`docs/problems/已处理的问题-YYYY-MM.md`中。
- 过程中发现的隐患，或者待定要不要处理的问题，记录到`docs/potential-problems/潜在问题.md`中。
- 如果有很复杂的问题，可以单独形成一个文档，然后这里提一句并提供相对链接过去。
- 如果是自己主机上遇到的不具有普适性的问题、不会所有人共同存在的问题，应写入到对应的加了`-personal`文件名后缀的文档。
- 过程中遇到的规范要求、用户的逻辑处理要求，应当记录到`docs/manners/规范.md`中。
