# 潜在问题

## 1. Copper 照明包裹系列缺失

**状态**：已修复（阶段四 commit `2f95375` + 阶段五 commit `ee98a1c`）

**描述**：`CasingTypes.ILLUMINATION_ENCASED` 枚举缺少 copper，导致铜材质没有照明包裹轴/齿轮的 Java 注册。资源文件（blockstate、model、texture）已全部存在，语言文件中只有 `copper_illumination_casing`，缺少 `copper_illumination_encased_*` 条目。`mineable/pickaxe` 和 `mineable/axe` 标签中也缺少铜照明包裹系列条目。战利品表也全部缺失。

**修复**：
1. 阶段四：`ILLUMINATION_ENCASED` 枚举加入 copper + 补充 3 条 illumination 翻译 + 应力值注册
2. 阶段五：补充 6 条 glass/clear_glass encased 翻译 + 补充 mineable 标签 + 新增 9 个 copper encased loot table

## 2. addLayer 方法已过时（7 个 deprecation 警告）

**状态**：待定

**描述**：`GlassBlockBuilders.java` 中 7 处调用 `BlockBuilder.addLayer(Supplier<Supplier<RenderType>>)` 被标记为 `@Deprecated`（removal）。Create 6.0+ 可能有替代 API。

**影响**：当前编译通过，仅警告。未来 Create 版本升级后可能编译失败。

**建议**：后续重建时查看 Create 6.0+ 的 BlockBuilder API，迁移到新方法。

## 5. Copper 系列贴图缺失

**状态**：待定

**描述**：Copper 材质的包覆轴/齿轮（glass 和 illumination 两个系列）引用了以下贴图，但这些贴图在当前项目、LoneStarFateZero 版和 c0nnor263 版中均不存在：
- `crystal_clear:block/copper_gearbox`（轴模型 opening 贴图）
- `crystal_clear:block/copper_backing`（齿轮模型 backing 贴图）
- `crystal_clear:block/encased_cogwheels/copper_encased_cogwheel_side`（齿轮模型 siding 贴图）
- `crystal_clear:block/encased_cogwheels/copper_encased_cogwheel_side_connected`（CT 连接贴图）
- `crystal_clear:block/encased_cogwheels/large_copper_encased_cogwheel_side`（大齿轮 siding 贴图）

Create 6.0.6 的 jar 中也没有 `copper_gearbox` 贴图（只有 `gearbox` 和 `brass_gearbox`）。

这是原作者 Adonis 在添加 copper 扩展时遗留的未完成工作。

**影响**：游戏中 copper 系列包覆方块会显示紫黑缺失贴图方块，但不会崩溃。编译不受影响。

**建议**：后续制作 copper 系列贴图，或改为复用 andesite/brass 的对应贴图作为临时替代。

## 6. 大齿轮代码 blockFolder 与手写 JSON parent 路径不一致

**状态**：待定

**描述**：`GlassBlockBuilders.java` 中大齿轮的 builder 代码设置 `blockFolder = "encased_large_cogwheel"`，但手写 JSON 的 parent 路径引用的是 `encased_cogwheel/block`（不是 `encased_large_cogwheel/block`）。资源目录中只有 `encased_cogwheel/` 目录，没有 `encased_large_cogwheel/`。

**影响**：当前手写文件可以正常工作（因为 JSON 直接指定了正确的 parent）。但如果未来运行 datagen 重新生成资源，代码中的 `blockFolder` 设置会导致找不到父模型而出错。

**建议**：后续如有 datagen 需求，修正代码中的 `blockFolder` 或补充 `encased_large_cogwheel/` 资源目录。

---

## 7. mineable/axe 标签与 pickaxe 内容相同

**状态**：待定

**描述**：`mineable/axe.json` 和 `mineable/pickaxe.json` 的 `values` 数组内容完全相同（除了 copper encased shaft 条目数量一致），所有方块同时被标记为可被镐和斧破坏。

**影响**：行为上没有严重问题（方块可以被斧头和镐破坏），但可能不是原设计意图。Create 原版的 encased 方块通常只放在 pickaxe 标签中。

**建议**：确认 c0nnor263 版和 LoneStarFateZero 版的行为，如果原版只使用 pickaxe，考虑从 axe 标签中移除 encased 系列（scaffolding 和 casing 保留在 axe 中）。
