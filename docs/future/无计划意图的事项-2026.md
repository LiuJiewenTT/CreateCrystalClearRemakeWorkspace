## 1. 小齿轮包覆箱模型替换

**日期**：2026-08-26

**来源**：commit `e94d013`（引入 Create 大包覆齿轮箱模型时的提交备注），原记录于未来参考选用事项 #1，后转移至此

**背景**：

大齿轮包覆箱模型已修复——引入了 Create 6.0.6 自带的 `encased_large_cogwheel/` 目录并修改了 60 个大齿轮 JSON 的 parent 引用，创造背包中大齿轮现在显示正常（详见已处理问题 #12 延伸修复）。同时统一了父模型纹理变量名（`#side`/`#1`/`#4` → `#siding`/`#backing`/`#opening`），修复了各材质侧面显示为 andesite 的问题。在引入大齿轮模型时，同时对小齿轮包覆箱的模型也做了略微更改，但视觉上没看出明显区别。

**事项**：

后续可以考虑也替换掉小齿轮包覆箱的模型，使用 Create 自带的 `encased_cogwheel/` 系列模型（如果有的话），与大齿轮保持一致的来源风格。

**当前状态**：

小齿轮包覆箱仍使用原有模型（`encased_cogwheel/` 目录，纯自建 3D 几何，不引用 Create 本体模型）。如需替换，需对比 Create 原版 `encased_cogwheel/` 模型与当前模型的差异，确认替换后视觉效果是否更优。
