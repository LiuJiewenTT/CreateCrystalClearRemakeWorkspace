## 四、执行规范

- 文件内容写入使用 Read/Edit/Write 工具，不使用 PowerShell（避免编码问题）
- 文件/目录移动使用 PowerShell（只移动，不修改内容）
- 内容修改与移动分开执行
- 不做删除操作（除非用户明确要求）
- Git 友好的移动改名流程：先 `git mv` 纯移动并提交 → 再编辑内容并提交，commit message 使用复选框语法
- 文档不提交 git（AIGC 水印需用户手动去除后再提交），代码可正常提交
- 每 10 次对话温习一遍工作区 README
