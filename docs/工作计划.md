## 二、本阶段目标：新功能开发 — 玻璃机壳包覆铜水管

### 背景

此功能完全不存在于上游仓库（LoneStarFateZero/CreatePrism）和原始项目（c0nnor263/Crystal-Clear-Arch），属于全新功能开发，不是"功能迁移与完善"。

Create 原版的普通铜机壳已经可以包覆铜水管（通过 `EncasingRegistry.addVariant` + `FluidPipeBlock` 实现的 `EncasableBlock` 接口）。本阶段的目标是让本模组的三种透明机壳（玻璃 / 透明玻璃 / 照明）也能包覆铜水管，使包覆后的水管可见内部流体。

### 调研结论（已完成）

- `FluidPipeBlock` 实现了 `EncasableBlock` 接口，可以通过 `EncasingRegistry.addVariant()` 注册包覆变体，与轴/齿轮注册方式一致
- 包覆后的方块应继承 `EncasedPipeBlock`，复用 `FluidPipeBlockEntity`
- `EncasedPipeBlock` 的六向连接属性通过 `transferSixWayProperties` 转移
- 原版 `PipeAttachmentModel` 会动态附加铜机壳 3D 外壳（`FLUID_PIPE_CASING`），贴图引用处替换为对应透明机壳贴图即可
- `AxisPipeBlock.useItemOn()` 硬编码检查铜机壳，不走 EncasingRegistry — **本次不支持玻璃直管包覆**
- 动力泵（`PumpBlock`）未实现 `EncasableBlock`，原版不支持包覆 — **动力泵包覆作为未来计划**

### 实施范围

| 包覆类型 | 材质 | 目标方块 |
|----------|------|----------|
| 玻璃包覆水管 | andesite / brass / copper / train | Create 铜水管（FluidPipeBlock） |
| 透明玻璃包覆水管 | andesite / brass / copper / train | 同上 |
| 照明包覆水管 | andesite / brass / copper / train | 同上 |

### 不在本次处理

- 玻璃直管（GlassFluidPipe / AxisPipeBlock）的包覆 — 需 Mixin 修改 `AxisPipeBlock.useItemOn()`，暂不支持
- 动力泵（Mechanical Pump）的包覆 — `PumpBlock` 未实现 `EncasableBlock`，需从零设计，作为未来计划
- addLayer 过时 API 迁移（待定）
- 空 Mixin / Ponder 场景（暂不处理）
