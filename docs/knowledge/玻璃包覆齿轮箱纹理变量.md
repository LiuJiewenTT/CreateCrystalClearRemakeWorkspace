# 玻璃包覆齿轮箱纹理变量说明

本模组（Create Crystal Clear）在 Create 原版包覆齿轮（encased cogwheel）的模型基础上，通过 5 个纹理变量（texture variables）实现不同材质和风格的视觉组合。这些变量定义在模型 JSON 的 `textures` 块中，由父模型 `crystal_clear:block/encased_cogwheel/block`（及其 `_top`、`_bottom`、`_top_bottom` 变体）引用。

## 5 个纹理变量

| 变量 | 作用 |
|------|------|
| **siding** | 齿轮箱侧面四周（南/北/东/西四面墙），是区分材质风格的主要载体 |
| **casing** | 齿轮箱顶面和底面的机壳板（玻璃壳），决定整体色调 |
| **opening** | 齿轮箱内部露出的齿轮/齿轮盒（顶面/底面中央开口处） |
| **backing** | 齿轮箱背面的木板衬底 |
| **particle** | 玩家破坏方块时飞出的粒子贴图，通常与 casing 一致 |

## 命名规则

以 `copper_glass_encased_cogwheel` 为例，各贴图路径为：

```
siding:    crystal_clear:block/encased_cogwheels/copper_encased_cogwheel_side
casing:    crystal_clear:block/copper_glass_casing
opening:   crystal_clear:block/copper_gearbox
particle:  crystal_clear:block/copper_glass_casing
backing:   minecraft:block/stripped_dark_oak_log_top
```

- **siding** 路径格式：`encased_cogwheels/{material}_encased_cogwheel_side`（大齿轮加 `large_` 前缀）
- **casing** 路径格式：`{material}_{type}_casing`（type 为 glass / clear_glass / illumination）
- **opening** 路径格式：`{material}_gearbox`（copper 系列为本模组自制，其余引用 Create 原版 `create:block/gearbox`）
- **particle** 通常与 casing 一致
- **backing** 统一使用原版去皮原木顶面贴图（brass/copper 用 `stripped_dark_oak_log_top`，其余用 `stripped_spruce_log_top`）
