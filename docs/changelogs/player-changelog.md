# 玩家变更日志

> 本文档记录玩家可感知的变更，面向模组使用者。
> 开发者向的内部变更请参阅 [developer-changelog.md](developer-changelog.md)。

---

## 2026-09-05

### 新增

- **玻璃机壳包覆铜水管**：铜水管现在可以用玻璃/透明玻璃/照明机壳右键包覆，共新增 12 个方块（3 种机壳 × 4 种材质）。包覆后水管保持六向流体传输功能，照明版发光
- **创造栏水管变体**：开启 `show_encased_variants` 配置后，创造栏中可看到 12 个水管包覆变体

### 已知限制

- 玻璃机壳包覆水管后内部铜管不可见（与 Create 原版铜机壳行为一致），透视效果计划在未来版本实现

## v2.0.0（2026-08-27）

基于 CreatePrism（Adonis 重构版）完全重建，更名回归 Create Crystal Clear。

### 新增

- **铜材质照明包覆系列**：铜材质现在支持照明机壳包覆传动杆、小齿轮和大齿轮（此前代码缺失，仅有资源文件）
- **铜材质包覆系列资源补全**：铜材质的玻璃/透明玻璃/照明包覆系列现在拥有完整的中英文翻译、战利品表和采集标签
- **铜系列贴图补全**：铜材质包覆轴/齿轮此前显示紫黑缺失贴图，现已手绘补全全部 5 个贴图
- **创造模式配置项**：新增客户端配置 `show_encased_variants`（默认关闭），控制创造栏是否显示包覆后的传动杆/齿轮方块。机壳和脚手架始终显示，包覆方块仍可通过 `/give` 获取
- **NeoForge 内置配置界面**：在 Mods 页面点击 Config 即可编辑配置，无需安装额外模组

### 修复

- **大齿轮显示为小齿轮**：大齿轮包覆箱在创造背包中显示的模型与小齿轮完全相同，无法区分。现已引入大齿轮专用模型，视觉效果与 Create 原版一致
- **大齿轮侧面材质错误**：引入大齿轮专用模型后，所有材质的大齿轮侧面都显示为安山岩颜色。现已修复纹理变量映射，各材质侧面正确显示
- **大齿轮侧面 UV 错误**：大齿轮包覆箱上下壳侧面显示异常（上壳空白、下壳区域选取不完整）。已修正 UV 坐标
- **照明齿轮侧面贴图未生效**：照明包覆齿轮的 CT 连接贴图实际未生效（路径不匹配）。现已使用独立贴图路径，照明版与普通版侧面可分别替换
- **安山照明大齿轮变体错误**：安山岩玻璃照明大齿轮系列 4 个模型文件存在贴图引用和 parent 指向错误。已修正
- **铜包覆底面贴图不一致**：铜材质包覆齿轮的底面贴图引用原版去皮深色橡木原木截面，与代码声明的铜底面不一致。已补全专用贴图并统一引用

### 移除

- **无关依赖**：开发环境不再加载炽海生机（Nether Depths Upgrade）及其依赖库 GeckoLib，创造背包中不再出现多余分类

### 已知问题（不影响正常使用）

- 7 个 `addLayer` 过时 API 警告，当前编译正常，未来 Create 版本升级后可能需迁移
- 机械臂交互 Mixin 和 Ponder 演示场景为空实现，暂不影响功能
- 5 个无关战利品表保留未清理，运行时不会被加载
