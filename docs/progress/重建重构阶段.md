### 7.1 问题

`build.gradle` 中有两个 `localImplementation` 依赖，由 Adonis 添加，Java 代码零引用，`neoforge.mods.toml` 未声明依赖关系：
- `nether-depths-upgrade`（炽海生机）— version 3.1.8
- `geckolib`（炽海生机的依赖库）— version QEqpUJ1G

## 八、铜系列贴图补全

### 8.1 问题

Copper 材质的玻璃/通透玻璃/照明包覆轴/齿轮/大齿轮在游戏中显示紫黑缺失贴图方块。实际影响显示的缺失贴图为 3 个（`copper_backing` 和 `copper_encased_cogwheel_side_connected` 在当前模型文件中未被引用，不影响显示）：

| 缺失贴图 | 引用路径 | 影响范围 | brass 参考贴图 |
|---------|---------|---------|---------------|
| `copper_gearbox` | `create:block/copper_gearbox`（36 个 model JSON 的 opening 字段） | 所有 copper 系列的 opening | Create jar 中 `brass_gearbox.png` |
| `copper_encased_cogwheel_side` | `crystal_clear:block/encased_cogwheels/copper_encased_cogwheel_side` | copper 系列的 cogwheel siding | `brass_encased_cogwheel_side.png` |
| `large_copper_encased_cogwheel_side` | `crystal_clear:block/encased_cogwheels/large_copper_encased_cogwheel_side` | copper 系列的 large_cogwheel siding | `large_brass_encased_cogwheel_side.png` |

三版本（当前项目、LoneStarFateZero、c0nnor263）都缺失这些贴图。Create 6.0.6 jar 中也没有 `copper_gearbox`（只有 `gearbox` 和 `brass_gearbox`）。

### 8.2 修复方案

**调色策略**：从 brass（黄铜）对应贴图通过 HSV 色相旋转生成 copper（铜）贴图。

- brass 主色调 HSV 色相约 20-25°（金黄棕系）
- copper 目标色相约 12-15°（橙红系），与项目中已有的 `copper_casing` 色调（H=15°）一致
- 主色调色相偏移 -8°，高光区域（hue > 40°）额外偏移 -20°
- 饱和度乘以 1.12（铜比黄铜略饱和），暗部明度乘以 0.95（增强对比）

**调色脚本**：`scripts/generate_copper_textures.py`

脚本从 brass 对应贴图逐像素调色生成 copper 贴图，保持 alpha 通道和图像尺寸不变。`brass_gearbox.png` 从 Create jar 提取后通过命令行参数传入，另两个 brass 贴图在项目内已有。
