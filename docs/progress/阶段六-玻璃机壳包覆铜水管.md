# 阶段六进展报告：玻璃机壳包覆铜水管

> 日期：2026-09-05
> 阶段：阶段六（新功能开发 — 玻璃机壳包覆铜水管）
> 状态：代码与资源完成，待 runClient 验证

## 一、功能概述

为 Create 原版铜水管（`FluidPipeBlock`）新增三种透明机壳包覆变体：玻璃、透明玻璃、照明。每种机壳支持 4 种材质（andesite/brass/copper/train），共 12 个新方块。包覆后水管保持六向流体传输功能，外壳可视。

此功能完全不存在于上游仓库和原始项目，属于全新功能开发。

## 二、与原版 Create 的区别

| 方面 | Create 原版 | 本模组 |
|------|-------------|--------|
| 包覆水管机壳 | 仅铜机壳 | 玻璃 / 透明玻璃 / 照明（各 4 材质） |
| 外壳材质 | 不透明铜质 | 半透明玻璃 / 透明玻璃 / 发光照明 |
| 内部铜管渲染 | 不渲染 | 不渲染（与原版一致；透视效果为未来计划） |
| 创造栏显示 | 不显示包覆变体 | 受 `show_encased_variants` 配置控制（默认关闭） |
| CT 连接纹理 | 原版 `EncasedCTBehaviour` | `GlassEncasedCTBehaviour` / `IlluminationEncasedCTBehaviour`（自定义连接逻辑） |
| 渲染层 | 原版 | 玻璃/透明玻璃 `cutout`，照明 `translucent` |

## 三、实现要点

### 3.1 方块类

- `GlassEncasedPipeBlock`：继承 `EncasedPipeBlock`，实现 `EncasedBlock`、`IBE<FluidPipeBlockEntity>`，添加透光属性（`propagatesSkylightDown`、`getShadeBrightness`）
- `IlluminationEncasedPipeBlock`：继承 `GlassEncasedPipeBlock`，设置 `lightLevel(15)`

### 3.2 BlockEntity

- `GLASS_ENCASED_PIPE`：覆盖 `GLASS_ENCASED_PIPES` + `CLEAR_GLASS_ENCASED_PIPES`（8 个方块）
- `ILLUMINATION_ENCASED_PIPE`：覆盖 `ILLUMINATION_ENCASED_PIPES`（4 个方块）
- 均复用 Create 原版 `FluidPipeBlockEntity`

### 3.3 注册链

- `CPBlocks`：3 组 `GlassBlockEntry` 列表（glass / clear_glass / illumination），每组 4 材质
- `GlassBlockBuilders`：`glassEncasedPipe()` 和 `illuminationEncasedPipe()` 两个 builder，含 `PipeAttachmentModel` 注册、CT 注册、`casingConnectivity` 注册
- `CrystalClear.registerEncasingVariants()`：在 `onCommonSetup` 中调用 `EncasingRegistry.addVariant(AllBlocks.FLUID_PIPE.get(), ...)` × 3 组

### 3.4 资源文件

| 类型 | 数量 | 说明 |
|------|------|------|
| blockstate JSON | 12 | multipart 格式（6 方向 × flat/open） |
| 模型 JSON (父模型) | 6 | `glass_encased_pipe/` 和 `illumination_encased_pipe/` 各 3 个（block/block_flat/block_open） |
| 模型 JSON (材质变体) | 24 | 12 个 flat + 12 个 open，引用父模型并传入材质贴图 |
| 语言文件 | 36 | en_us + zh_cn + en_ud 各 12 条 |
| mineable 标签 | 12 | pickaxe 含全部 12 个 pipe（axe 不含，与原版一致） |
| 战利品表 | 12 | 均掉落 Create 原版铜水管 |
| 贴图 | 复用 | 使用已有机壳贴图（`{材质}_glass_casing` / `{材质}_clear_glass_casing` / `{材质}_illumination_casing` 及 `_connected` 变体），opening 贴图复用 gearbox 系列 |

### 3.5 CT 连接与机壳连接性

- `GlassEncasedCTBehaviour` / `IlluminationEncasedCTBehaviour`：继承 `EncasedCTBehaviour`，自定义 `connectsTo` 逻辑
- `casingConnectivity`：仅当对应面管道未贯通（`!state.getValue(FACING_TO_PROPERTY_MAP.get(face))`）时显示机壳面

## 六、技术发现：原版包覆水管不渲染内部铜管

本轮排查的核心发现：原版 Create 的铜机壳包覆水管本身也不渲染内部铜管。原因：

1. `FluidPipeBlock.isPipe()` 检查 `instanceof FluidPipeBlock`，而 `EncasedPipeBlock extends Block`（非 `FluidPipeBlock`）
2. `StandardPipeFluidTransportBehaviour.getRenderedRimAttachment()` 对所有 `EncasedPipeBlock` 子类返回 `AttachmentTypes.NONE`
3. 包覆后可见的只有 blockstate JSON 静态模型（薄片外壳）

这意味着实现玻璃机壳独有的"透视内部铜管"效果需要自定义渲染逻辑，属于原版不具备的新功能。详见 `docs/problems/已处理的问题-2026-09.md` #21。
