# 铜透明包覆水管特性是否存在的前期探索

> 日期：2026-08-27
> 目的：确认当前重建项目与原始项目是否包含"给铜水管添加透明机壳包覆"的功能代码

## 结论

**两个项目均不包含铜水管（fluid pipe）的透明/玻璃机壳包覆功能。**

- 当前重建项目：Java 源码零 pipe 匹配，`EncasingRegistry.addVariant()` 仅注册 Shaft / Cogwheel / Large Cogwheel 三种机械方块的包覆，无任何 pipe 注册
- 原始项目（c0nnor263）：Java 源码同样零 pipe 匹配，但存在 2 个废弃的半成品模型 JSON（`copper_glass_encased_pipe/block_open.json`、`block_flat.json`），无 Java 注册、无 blockstate、无 item model，系早期实验性遗留

## 调查过程

### 当前重建项目（repo/Create-Crystal-Clear）

- Java 源码中搜索 `pipe`（不区分大小写）：0 匹配
- `EncasingRegistry.addVariant()` 只注册了三类方块：Shaft（轴）、Cogwheel（小齿轮）、Large Cogwheel（大齿轮）
- `assets/crystal_clear/` 命名空间下无任何 pipe 相关文件
- `assets/create/` 命名空间下有 pipe 贴图/blockstate（如 `fluid_pipe.json`、`glass_fluid_pipe.json`、`encased_fluid_pipe.json`），但这些是对 Create 原版水管方块的资源覆盖，不是新增包覆水管方块

### 原始项目（referring_repos/c0nnor263）

- Java 源码中搜索 `pipe`：0 匹配
- 资源目录中找到 2 个半成品模型 JSON：

| 文件 | 内容 | 废弃证据 |
|------|------|----------|
| `copper_glass_encased_pipe/block_open.json` | 引用 `create:block/encased_pipe` 贴图，仅两个薄面板元素（z=15~17） | 无 blockstate、无 item model |
| `copper_glass_encased_pipe/block_flat.json` | 引用 `create_crystal_clear:block/copper_glass_casing` 贴图（命名空间 `create_crystal_clear` 与实际 `crystal_clear` 不一致） | 无 Java 注册、命名空间错误 |

- 这 2 个文件是孤立资产（orphaned assets）：无 Java 注册、无 blockstate、无 item model、模型极简、命名空间不一致，系早期实验性遗留，从未被使用

## 两项目实际已有的包覆功能对比

| 包覆类型 | 原始项目 (c0nnor263) | 当前重建项目 |
|----------|:---:|:---:|
| 玻璃机壳（Casing） | andesite/brass/copper/train | andesite/brass/copper/train |
| 玻璃脚手架 | andesite/brass/copper | andesite/brass/copper/train |
| 玻璃包覆轴（Encased Shaft） | andesite/brass/train（无 copper） | andesite/brass/copper/train |
| 玻璃包覆小齿轮（Encased Cogwheel） | andesite/brass/train（无 copper） | andesite/brass/copper/train |
| 玻璃包覆大齿轮（Encased Large Cogwheel） | andesite/brass/train（无 copper） | andesite/brass/copper/train |
| 水管包覆（Encased Pipe） | 无（仅 2 个废弃半成品模型） | 无 |

> 注：机械动力（Create）原版的普通铜机壳已经可以包覆铜水管和动力泵，这是 Create 本体的功能，不在本扩展 mod 的范围内。本探索关注的是"透明/玻璃机壳"包覆水管——这一功能两个项目均未实现。
